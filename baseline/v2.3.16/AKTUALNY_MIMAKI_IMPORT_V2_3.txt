- Temporary files are written to W:\Temp\MimakiImposer and deleted after import.
Crop / positioning:
- Source artwork is copied through a crop canvas before imposition.
- Every product slot uses the real slot geometry from the template plus 3 mm bleed on every side as the crop canvas.
- PVC/card layouts use the same slot+bleed canvas logic as USB/pens/lighters; fixed 90 x 60 mm is only a low-level fallback if geometry cannot be read.
- If the source page already looks like the crop canvas, the crop is centered on the source page.
- If the source page is a large working page, the crop is centered on the selected/grouped artwork.
- PowerClip is attempted with CenterInContainer=False so non-centered graphics stay non-centered inside the crop canvas.

Form v2.3:
- Main green action button uses caption Be + ChrW$(382), displayed as the short Run label in Corel.
- P/Z workflow is implemented in the panel: KOPIE, P ZZZ, PPP Z, PZ PZ.
- If the source document has one page, the panel automatically chooses copies mode and range 1.
- If the source document has multiple pages, the panel fills range 1-N and keeps the last P/Z workflow; if the last mode was KOPIE, it defaults to PZ PZ.

Naming unchanged:
- Output CDR name: [ID]_[template]_[P/Z].cdr
- PDF names: [ID]_[template]_[P/Z]_p01.pdf, _p02.pdf, ...
- KARTA/KARTY/TEMPLATE_KARTY maps to pvckarta.
- Template layers are kept visible/non-printable/locked in working CDR and hidden from production PDF.

- Temp workflow now creates a real white CMYK slot-size PowerClip canvas with 3 mm bleed on every side, rasterizes that selected canvas at 600 dpi, then exports/imports only that bitmap.
- This prevents Corel from stretching the artwork by visible object bounds instead of the template slot canvas.
- Expected debug log after import: "create temp crop bitmap", "temp rasterized canvas size mm", "export selected temp bitmap", "try ExportBitmap TIFF direct".
