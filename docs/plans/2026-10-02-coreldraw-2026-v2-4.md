# Mimaki Imposer v2.4 CorelDRAW 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Each task is reviewed before proceeding; every GitHub change is made on the v2.4 branch.

**Goal:** Deliver a CorelDRAW 2026 v27.2 implementation that preserves v2.3.16 TIFF production behavior and adds a separate editable-vector placement mode.

**Architecture:** Freeze the exact v2.3.16 source on the stable line, then develop v2.4 on a branch. Keep VBA as the in-process host; separate entry/UI, source and template discovery, TIFF preparation, vector placement, and output/export responsibilities. Both placement paths share verified slot geometry and orientation rules, while the TIFF path remains the default and has no vector-mode fallback.

**Tech Stack:** CorelDRAW Graphics Suite 2026 v27.2 object model, VBA/UserForm, GitHub connector for repository changes and pull requests.

**Spec:** [docs/SPEC_V2_4_CORELDRAW_2026.md](../SPEC_V2_4_CORELDRAW_2026.md)

## Global Constraints

- Target host is CorelDRAW Graphics Suite 2026 v27.2.
- Keep the v2.3.16 TIFF behavior recoverable and unchanged as the production fallback.
- Slot layers end in `SLOT`; slot objects require outline spot color `CutContour1`.
- Print Data TIFF rasterization is CMYK at 600 dpi; `RDG_WHITE` is detected by spot color and stays vector spot data on WHITE.
- Every slot uses its own geometry plus 3 mm bleed per side.
- Keep F3 and duplex P/Z/PZZ/PPZ behavior limited to cards.
- Save output beside the source, falling back to the configured default folder.
- New Corel API calls must match the v27.2 documentation and be checked in the target host before replacing working calls.
- Do not report speed improvements without repeatable timing against the v2.3.16 baseline.

## Review Focus

- Selection changed or cleared while the modeless panel is open; use the captured source document/range and never place an empty or stale range.
- Multiple source pages, blank pages, and a selected range; preserve source-page-to-slot indexing and expected output page count.
- Mixed portrait/landscape slots with asymmetric artwork; fit, rotate, align, and apply 3 mm bleed independently for each slot.
- `RDG_WHITE` on any source layer and pages with/without white; preserve the spot vector and emit `_W` PDF only for pages containing white.
- Failures during bitmap conversion, import, placement, save, or export; restore document state, optimization, command groups, and temporary data.
